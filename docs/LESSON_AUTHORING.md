# NOVA Lesson Authoring Guide

## Overview
The NOVA interactive lesson player is completely decoupled from UI code. Lessons are authored as structured Dart models (or JSON payloads generated by an LLM) and consumed by `LessonPlayerScreen` through `LessonRegistry`.

Adding a new lesson requires **zero changes** to screen widgets.

---

## 1. Lesson Architecture & Data Models

All models reside in `lib/features/lessons/domain/models/lesson_models.dart`:

```dart
class Lesson {
  final int standard;
  final int level;
  final String id;
  final String titleEn;
  final String titleMr;
  final String theme;
  final List<String> concepts;
  final List<StoryBeat> beats;
  final List<LessonQuestion> questions;
  final LessonSummary summary;
  final String? nextLessonId;
}
```

### Supported Activity Types
1. **Story Beats (`StoryBeat`)**:
   - Sequential animated story scenes.
   - Segmented narration with phonetic overrides (`ttsOverride`), language tags (`mr-IN`, `en-IN`), and visual cues (`VisualCue.roof`, `VisualCue.tractor`, etc.).
   - Child-friendly manual controls: `Listen Again`, `Next`, and `Skip Story`.
   - Optional speech trigger (`requiresMicInteraction: true`).

2. **Picture Multiple Choice (`QuestionType.tap` / `QuestionType.tapOrVoice`)**:
   - 2 or more large picture option cards.
   - Text label, sublabel, and visual key.
   - Gentle, non-shaming retries on mistakes.
   - Cheerful checkmark celebration and deliberate `Continue` button upon correct answer.

3. **Match the Following (`QuestionType.matchPairs`)**:
   - Two columns: Left (Pictures/Items) and Right (Concepts/Words).
   - Dual input support: **Drag-and-drop** AND **Tap-to-match** (accessible fallback).
   - Completed pairs lock with a green checkmark.
   - Real-time progress indicator (e.g. `2 of 3 pairs matched`).

4. **Summary & Celebration (`LessonSummary`)**:
   - Narration summarizing core concepts learned.
   - Structured takeaway points in Marathi & English.
   - 3 gold star rewards, confetti animation, and persistence to `AppState.completeLevel()`.

## 2. Authoring a New Lesson

### Step 1: Define the Lesson Data
Create or generate a new file, e.g. `lib/features/lessons/data/level_2_data.dart`:

```dart
import '../domain/models/lesson_models.dart';

const Lesson level2Lesson = Lesson(
  standard: 1,
  level: 2,
  id: 'std1_level2_counting',
  titleEn: 'Counting in the Orchard',
  titleMr: 'बागेत मोजणी',
  theme: 'Orchard & Numbers',
  concepts: ['Maths – Numbers 1 to 5', 'EVS – Fruits & Trees'],
  beats: [
    StoryBeat(
      id: 'beat1_orchard',
      sceneId: SceneId.farm,
      narration: NarrationLine(
        displayText: "बघ चिंटू, झाडावर सुंदर आंबे लागले आहेत!",
        semanticDescription: "Chintu and NOVA arrive at the mango orchard.",
        segments: [
          NarrationSegment(text: "बघ चिंटू, झाडावर सुंदर आंबे लागले आहेत!", languageTag: "mr-IN"),
        ],
      ),
    ),
  ],
  questions: [
    LessonQuestion(
      id: 'q1_count_mangoes',
      subject: 'Maths',
      prompt: NarrationLine(
        displayText: "झाडावर किती आंबे आहेत ते मोजा.",
        semanticDescription: "Count how many mangoes are on the tree.",
        segments: [NarrationSegment(text: "झाडावर किती आंबे आहेत ते मोजा.", languageTag: "mr-IN")],
      ),
      type: QuestionType.tap,
      correctOptionId: 'three',
      options: [
        QuestionOption(
          id: 'two',
          label: '२ (Two)',
          visualKey: 'two_mangoes',
          semanticLabel: 'Two mangoes',
        ),
        QuestionOption(
          id: 'three',
          label: '३ (Three)',
          visualKey: 'three_mangoes',
          semanticLabel: 'Three mangoes',
        ),
      ],
      correctFeedback: [
        NarrationLine(
          displayText: "शाब्बास! अगदी बरोबर! ३ आंबे आहेत! ⭐",
          semanticDescription: "NOVA celebrates.",
          segments: [NarrationSegment(text: "शाब्बास! अगदी बरोबर!", languageTag: "mr-IN")],
        ),
      ],
      retryFeedback: [
        NarrationLine(
          displayText: "छान प्रयत्न! पुन्हा एकदा मोजून बघूया.",
          semanticDescription: "NOVA is encouraging.",
          segments: [NarrationSegment(text: "छान प्रयत्न! पुन्हा एकदा मोजून बघूया.", languageTag: "mr-IN")],
        ),
      ],
    ),
  ],
  summary: LessonSummary(
    overallNarration: NarrationLine(
      displayText: "शाब्बास! आज आपण बागेत मोजायला शिकलो!",
      semanticDescription: "NOVA summarizes.",
      segments: [NarrationSegment(text: "शाब्बास! आज आपण बागेत मोजायला शिकलो!", languageTag: "mr-IN")],
    ),
    summaryPoints: [
      NarrationLine(
        displayText: "Numbers 1-5 — संख्या १ ते ५",
        semanticDescription: "Numbers 1-5",
        segments: [],
      ),
    ],
  ),
);
```

### Step 2: Register in `LessonRegistry`
In `lib/features/lessons/data/lesson_registry.dart`:

```dart
class LessonRegistry {
  static Lesson? getLesson(int standard, int level) {
    if (standard == 1 && level == 1) return level1Lesson;
    if (standard == 1 && level == 2) return level2Lesson;
    return null;
  }
}
```

## 3. LLM Integration Pathway

To ingest dynamic lessons from an LLM in the future:
1. Provide the LLM with the JSON schema mirroring the `Lesson` Dart model.
2. The LLM generates the lesson JSON.
3. A `LessonFromJson(Map<String, dynamic> json)` parser loads the model.
4. Pass the deserialized `Lesson` object into `ref.read(lessonEngineProvider.notifier).loadLesson(lesson)`.
5. The exact same player renders the interactive story, audio, quizzes, matching, and celebration seamlessly.
